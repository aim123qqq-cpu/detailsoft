# Публикация DetailFlow в RuStore

Всё, что нужно для карточки приложения в RuStore Консоли. Требования магазина — по справке RuStore (иконка 512×512 без прозрачности, от 3 скриншотов телефона до 3 МБ, название до 30 символов, короткое описание до 80, полное до 4000).

## Что загрузить

| Что | Файл |
|---|---|
| Приложение | `artifacts/DetailFlow-1.0.0.apk` — подписанный APK (собирается `node scripts/build-mobile.mjs apk`, для всех телефонов) |
| Иконка 512×512 | `mobile/store/icon-512.png` |
| Скриншоты телефона | `mobile/store/screenshots/01-orders.png` … `06-statistics.png` (1080×2400, PNG) |
| Обложка (для других магазинов) | `mobile/store/feature-1024x500.png` |

**Почему APK, а не AAB.** RuStore принимает оба формата, но для AAB подпись нужно отдельно добавить в консоли магазина. С APK ключ загрузки остаётся только у владельца. Каждая следующая версия подписывается тем же ключом и с бо́льшим `versionCode` (`mobile/app.json`).

Ключ загрузки и `keystore.properties` лежат вне проекта, в `C:\Users\USER\.detailflow`. Эту папку нужно хранить в резервной копии: без ключа обновить приложение в магазине нельзя.

## Тексты

**Название (до 30):** DetailFlow

**Короткое описание (до 80):** Запись, приёмка со схемой авто, смета, работы и акты для детейлинг-центра

**Полное описание:**

DetailFlow — рабочее приложение детейлинг-центра: от звонка клиента до выдачи автомобиля.

Запись. Найдите клиента по телефону или госномеру, выберите автомобиль, услуги и свободное время. Цена и длительность считаются по классу автомобиля и прайсу центра.

Приёмка. Выберите тип кузова — схема автомобиля сменится на нужную. Каждый элемент пронумерован: нажмите на капот, дверь или колесо, выберите замечание и тяжесть, сделайте фото. Номера на схеме совпадают с актом приёмки.

Смета и согласование. Услуги из записи, рекомендации по осмотру, свои строки. Решение клиента фиксируется с версией сметы, способом согласования и ответственным.

Работы. Мастер видит свои заказы, отмечает операции, ставит паузу с причиной и завершает работу.

Выдача и акты. Фото до и после, чек-лист выдачи, акты приёмки и выдачи с подписью клиента пальцем на экране. Акт можно отправить клиенту в PDF.

Без интернета. Если связь пропала, работа продолжается: изменения сохраняются на телефоне и отправляются на сервер центра, когда связь вернётся.

Для руководителя. Статистика по записям и заказам, каталог услуг с ценами по классам авто, команда и роли с правами, график работы центра.

Приложение работает с сервером вашего центра: адрес сервера вводится при первом запуске. Вход — через Telegram, MAX или по коду доступа сотрудника.

**Категория:** Бизнес (или «Инструменты», если «Бизнес» недоступна).

**Теги (до 5):** детейлинг, автосервис, CRM, запись клиентов, приёмка автомобиля

**Возрастной рейтинг:** 0+ (в приложении нет контента, требующего ограничений).

## Безопасность данных

Для раздела «Безопасность данных пользователя»:

- **Какие данные:** имена и телефоны клиентов и их автомобили (вводят сотрудники центра); фото автомобилей; подпись клиента в акте; имя сотрудника и привязка его Telegram или MAX для входа.
- **Где хранятся:** на сервере центра, которым пользуется организация. На телефоне — рабочая копия для работы без связи, она стирается при удалении аккаунта.
- **Передача третьим лицам:** нет. Рекламы и аналитики сторонних сервисов нет.
- **Разрешения:** камера — для фото при приёмке и выдаче (по нажатию кнопки, с запросом разрешения). Фото из галереи выбираются через системный выбор файла, без доступа ко всей галерее.
- **Удаление аккаунта:** «Профиль → Удалить аккаунт» в приложении.
- **Шифрование при передаче:** HTTPS, если сервер центра работает по HTTPS. В локальной сети центра (адрес вида 192.168…) приложение может работать и по HTTP — для сервера в интернете нужен HTTPS.
- **Политика конфиденциальности:** https://aim123qqq-cpu.github.io/detailsoft/privacy/ (`public/privacy/index.html`). **Перед публикацией** впишите в неё оператора данных (ФИО или организацию) и email для обращений.

## Что сделать владельцу

1. Зарегистрироваться в RuStore Консоли как разработчик (лично, с подтверждением личности; для организации — от её имени).
2. Вписать оператора данных и email в политику конфиденциальности; опубликовать (сайт обновится через GitHub Pages).
3. Создать приложение, загрузить APK, иконку, скриншоты и тексты отсюда, указать контакт разработчика (email или сайт) и отправить на проверку.
