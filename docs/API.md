# API — итерация 1 Customer & Vehicle

Все маршруты `/api/*`, кроме `/api/health`, требуют `Authorization: Bearer <session-token>`. Tenant извлекается из серверной сессии; переданный клиентом `x-tenant-id` не определяет область данных.

Ошибки имеют единую форму:

```json
{"error":{"code":"validation_error","message":"Проверьте данные"}}
```

## Реализованные маршруты

| Метод | Маршрут | Назначение |
|---|---|---|
| `GET` | `/api/customers?phone=` | Частичный поиск клиентов по нормализованному телефону; всегда возвращает `{ items: [] }` |
| `POST` | `/api/customers` | Создание клиента из `{ name, phone }` с сохранением введённого отображаемого номера |
| `GET` | `/api/customers/{id}/vehicles?includeArchived=false` | Автомобили клиента по активным временным связям |
| `GET` | `/api/vehicles?plate=` | Частичный поиск по нормализованному госномеру в текущем tenant |
| `GET` | `/api/vehicle-catalog/variants?q=` | Варианты `марка → модель → поколение → кузов → системный класс` |
| `POST` | `/api/vehicles` | Атомарное создание автомобиля и `CustomerVehicle`; возможный дубль возвращает `409 possible_duplicate` |
| `PATCH` | `/api/vehicles/{id}` | Изменение статуса на `active`, `inactive` или `sold` без удаления истории |
| `GET` | `/api/orders/{id}` | Минимальный read-only контракт для проверки неизменности исторических ссылок |

Списковые маршруты ограничены десятью результатами. Параметры SQL передаются через prepared statements. Тело JSON ограничено 64 КиБ.

## Отличия от предложений исходной спецификации

- Пути основных ресурсов совпадают с предложенными, но отдельные маршруты создания/закрытия `CustomerVehicle` пока не опубликованы: в этом инкременте связь создаётся атомарно вместе с автомобилем.
- Смена владельца с аудитом, ручное добавление отсутствующей модели и редактирование tenant-класса остаются следующими срезами итерации 1.
- Полноценные `Booking`, услуги и расчёт цены не реализованы; экран «Услуги» является честной границей следующей итерации.
- SQLite и bearer-токены — локальная реализация прототипа; production-хранилище и существующая auth-система в исходном пустом репозитории отсутствовали.
