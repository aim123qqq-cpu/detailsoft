# Публикация DetailFlow в Huawei AppGallery

Пошагово, от регистрации до публикации. Сверено с практикой публикации на 2 ноября 2026 года. Если экран AppGallery Connect отличается от описанного, ориентируйтесь на смысл шага.

Готовый пакет файлов собирается командой `node scripts/store-packages.mjs` в `artifacts/AppGallery/` (в git не попадает): APK, иконка 216×216, скриншоты, тексты и данные для проверки.

## Почему AppGallery нам подходит без доработок

На телефонах Huawei нет сервисов Google. DetailFlow их и не использует: нет Firebase, карт Google и входа через Google. Поэтому приложение работает на Huawei без изменений: вход, камера, работа без сети, PDF-акты.

## Сколько это займёт

| Этап | Время |
|---|---|
| Huawei ID и проверка личности | 1–3 рабочих дня |
| Заполнение карточки | 1 час |
| Проверка первой версии | 3–5 рабочих дней |

Взноса за регистрацию нет. Закрытого тестирования, как в Google Play, AppGallery не требует.

## Шаг 1. Huawei ID и аккаунт разработчика

1. Откройте [developer.huawei.com](https://developer.huawei.com/consumer/ru/) → «Регистрация». Создайте **Huawei ID** по email или телефону. Регион — **Россия** (поменять потом нельзя).
2. Войдите и пройдите **проверку личности (Identity verification)**:
   - тип — **Индивидуальный разработчик** (Individual);
   - ФИО латиницей и кириллицей как в паспорте;
   - фото или скан паспорта;
   - банковская карта или подтверждение по лицу — как предложит форма;
   - адрес, телефон, email (`detailfow@mail.ru`).
3. Дождитесь письма об одобрении: обычно 1–3 рабочих дня. Если попросят уточнить документы, это видно в консоли во вкладке проверки.

## Шаг 2. Создать приложение

[AppGallery Connect](https://developer.huawei.com/consumer/ru/service/josp/agc/index.html) → **«Мои приложения» → «Новое приложение»**:

| Поле | Значение |
|---|---|
| Тип пакета | APK |
| Устройство | Мобильный телефон |
| Название | `DetailFlow` |
| Категория | Приложение |
| Язык по умолчанию | Русский |

## Шаг 3. Информация о приложении

Вкладка **«Информация о приложении»** (App information):

| Поле | Значение / файл |
|---|---|
| Название (до 64) | `DetailFlow` |
| Краткое описание (до 80) | из `3-тексты-карточки.txt` |
| Полное описание (до 8000) | `4-полное-описание.txt` |
| Иконка 216×216, без прозрачности | `1-иконка-216.png` |
| Скриншоты телефона (3–8, вертикальные) | все 6 из `6-скриншоты-1080x1920`, по порядку |
| Рекламная картинка 1024×500 (необязательно) | `2-обложка-1024x500.png` |
| Категория | Приложения → **Бизнес** (Business). Важно выбрать сразу: сменить потом можно только через поддержку |
| Политика конфиденциальности | `https://detailflow.ru/privacy/` |
| Email поддержки | `detailfow@mail.ru` |
| Сайт | `https://detailflow.ru` |

**Политика должна быть видна до входа.** AppGallery отклоняет приложения, где пользователь не видит политику конфиденциальности при первом запуске или на экране входа. В DetailFlow ссылки «Политика обработки персональных данных» и «Пользовательское соглашение» есть внизу экрана входа, а при создании центра — две отдельные галочки.

## Шаг 4. Возрастной рейтинг

Анкета возрастного рейтинга: на все вопросы о насилии, азартных играх, нежелательном контенте, покупках — **Нет**. Ожидаемый рейтинг — **3+**. AppGallery проверяет рейтинг вручную и не даст его занизить, но у нас занижать нечего.

## Шаг 5. Приватность данных

Если консоль попросит заполнить раздел о данных (Privacy / Data security), отвечайте как в [GOOGLE_PLAY.md](GOOGLE_PLAY.md), «Безопасность данных»:
- собираются имя, email для входа, телефоны клиентов центра, данные автомобиля и подпись, фото автомобиля, журнал действий в заказах;
- всё для функций приложения и управления аккаунтом;
- третьим лицам не передаётся, рекламы и аналитики нет;
- при передаче шифруется (HTTPS);
- удаление аккаунта — «Профиль → Удалить аккаунт», либо `https://detailflow.ru/privacy/#delete`.

Разрешения с объяснением:
- **Камера** — фото автомобиля при приёмке и выдаче, только по нажатию кнопки;
- **Чтение памяти** (только Android 12 и ниже) — выбрать фото из галереи для приёмки.

## Шаг 6. Распространение

Вкладка **«Распространение»** (Distribute):
1. **Страны и регионы**: Россия, а также Беларусь, Казахстан и другие по желанию.
2. **Платное или бесплатное**: Бесплатное.
3. **Версия → Пакет**: загрузите `0-DetailFlow-1.1.0.apk`. Консоль прочитает пакет `ru.detailflow.app`, версию 1.1.0 (код 11).
   - **Подпись**: AppGallery предложит свою подпись приложений (App signing). Можно отказаться: APK уже подписан нашим ключом, тем же, что для RuStore. Тогда обновления из RuStore и AppGallery взаимозаменяемы.
4. **Информация для проверки** (Review information / Test account): текст из `5-доступ-для-проверки.txt` — код тестового центра и как войти. Имя пользователя оставьте пустым или напишите «не требуется», код — в поле пароля.
5. **Что нового** (Release notes): из `3-тексты-карточки.txt`.
6. **Время публикации**: сразу после проверки.

## Шаг 7. Отправить на проверку

«Отправить» (Submit). Проверка 3–5 рабочих дней. Результат придёт письмом и будет виден в консоли. При отказе в письме указаны пункт правил и скриншоты. Исправьте и отправьте снова: повторная проверка обычно быстрее.

## Обновления

1. Увеличьте `versionCode` в `mobile/app.json` (сейчас 11), при заметных изменениях и `version`.
2. `node scripts/build-mobile.mjs apk` → `node scripts/store-packages.mjs`.
3. AppGallery Connect → приложение → «Версия» → «Новая версия» → загрузить APK, «Что нового» → на проверку.

Подписывайте тем же ключом загрузки (`C:\Users\USER\.detailflow\detailflow-upload.jks`), иначе AppGallery не примет обновление.

## Частые причины отказа и как их избежать

| Причина | Как у нас |
|---|---|
| Проверяющий не смог войти | В «Информации для проверки» код тестового центра. Проверьте его перед отправкой. |
| Политика не видна при входе | Ссылки внизу экрана входа. |
| Нестабильная работа на устройствах Huawei | Приложение не зависит от сервисов Google. Если отклонят, в письме будет модель устройства, перепроверим. |
| Описание не совпадает с функциями | Тексты описывают только то, что есть в приложении. |
| Неверная категория | Бизнес. |
