# DetailFlow

Первый рабочий инкремент mobile-first CRM: поиск клиента по телефону, поиск автомобиля по госномеру, выбор одного из нескольких автомобилей и добавление новой машины с автоподбором кузова.

## Запуск

Требуется Node.js 24+ и pnpm 11+.

```powershell
pnpm install
pnpm dev
```

Интерфейс откроется на `http://127.0.0.1:5173`. Для production-проверки:

```powershell
pnpm build
pnpm start
```

Приложение будет доступно на `http://127.0.0.1:4173`.

Демо-поиск: `+7 913 123-45-67`. У клиента есть Mazda 3 BL и Toyota Camry XV70.

## Архитектура инкремента

- `migrations/001_customer_vehicle.sql` — tenant-scoped схема SQLite. `Customer` и `Vehicle` разделены временной связью `CustomerVehicle`; госномер намеренно не имеет жёсткого `UNIQUE`.
- `server/` — HTTP API на стандартных модулях Node.js и встроенном `node:sqlite`. Tenant определяется сервером из bearer-сессии, а не из заголовка, выбранного клиентом.
- `src/` — React mobile UI с debounce-поиском, состояниями загрузки/ошибки/пустого результата и прямым переходом на услуги.
- `tests/` — модульные, API-интеграционные и Chromium end-to-end проверки.
- `artifacts/` — локальные скриншоты реального e2e-прохождения; в Git не добавляются.

Демо-токены нужны только для локального прототипа. Перед production-развёртыванием их следует заменить существующей системой аутентификации и авторизации.
